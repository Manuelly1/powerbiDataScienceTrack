# 📊 Power BI for Business Intelligence and Data Science

Este repositório foi criado para documentar minha jornada de aprendizado no curso **Microsoft Power BI para Business Intelligence e Ciência de Dados**, oferecido pela **Data Science Academy (DSA)**.

O objetivo é centralizar dashboards, datasets, roteiros práticos e resumos conceituais desenvolvidos ao longo das unidades do curso.

---

## 📘 Estrutura dos Capítulos

Os capítulos seguem uma estrutura padrão. Cada pasta pode conter:

- Dashboard desenvolvido na unidade (`.pbix`);
- Datasets utilizados;
- Roteiro do laboratório ou mini-projeto;
- Arquivo **`overview.md`**, com o resumo conceitual da unidade.
